---

## 1. Tujuan

1. **Bazar**: buka bazar → bawa barang dari gudang → jual dari bazar → tarik sisa → tutup bazar.
2. **Parkir**: tahan keranjang (maks 3, bernama) agar bisa melayani pembeli lain.
3. Menjaga **aturan stok** yang ditegaskan pemilik pada Phase 2B:
   gudang berkurang saat **dibawa**, bazar berkurang saat **dijual**, penjualan bazar
   **tidak** menyentuh gudang.

## 2. Yang dibangun

### 2.1 Repository

| Fungsi baru | Tugas |
| --- | --- |
| `ringkasanBazar(bazarId)` | dibawa, terjual, sisa, uang masuk, jumlah barang |
| `tutupBazar(id, peta)` | kembalikan sisa ke gudang, tandai selesai, simpan ringkasan |
| `tarikDariBazar(id, produk, n)` | tarik sebagian sisa tanpa menutup bazar |
| `adaParkirUntukBazar(id)` | cegah tutup bazar bila masih ada keranjang tertahan |

`parked_carts` mendapat kolom **`bazarId`** agar keranjang tahu stok mana yang dipakai.

### 2.2 Layar

| Layar | Berkas |
| --- | --- |
| 15 Bazar | `screens/Bazar.tsx` |
| 16 Alokasi Barang | `screens/AlokasiBazar.tsx` |
| 17 Tutup Bazar | `screens/TutupBazar.tsx` |
| Keranjang + parkir | `screens/Keranjang.tsx` (kolom nama pembeli, daftar Tertahan, tombol Parkir) |
| Katalog & detail | stok yang tampil = **saldo bazar** bila bazar aktif |

### 2.3 Perilaku saat bazar aktif

- Katalog menampilkan **stok bazar**, bukan stok gudang.
- Keranjang dibatasi saldo bazar.
- Transaksi menyimpan `bazarId`, sehingga `simpanTransaksi` memakai sumber stok **bazar**
  (aturan Phase 2B otomatis menolak bila keliru memakai gudang).
- Keranjang tertahan menyimpan `bazarId`; **tutup bazar ditolak** bila masih ada parkir bazar itu.

## 6. Yang masih tertunda

1. **Resi PDF belum ada** → Phase 5. Tombol "Buat Resi" masih penanda.
2. **Keranjang belum tahan tutup aplikasi** — masih state memori. Kandidat perbaikan berikutnya.
3. Parkir **tidak** memvalidasi ulang saldo bazar saat dilanjutkan (baru divalidasi saat Simpan).
   Contoh: saldo bazar turun karena Windows lain menyimpan transaksi. Saat ini ditangkap
   `simpanTransaksi` dengan pesan "Stok bazar tidak cukup." — lebih baik ditampilkan lebih awal.
4. Bazar belum memakai tanggal mulai/selesai (form hanya nama).
5. Unggah foto ke R2 → Phase 6.
