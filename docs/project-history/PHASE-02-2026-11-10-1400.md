---

## 1. Tujuan

Menyiapkan kerangka kerja yang benar sebelum fitur dibuat:

1. Proyek Vite + React + TypeScript yang bisa di-build dan dijalankan.
2. **PWA**: manifest, ikon, service worker app-shell — aplikasi terbuka tanpa internet.
3. **Skema IndexedDB** yang sudah memuat bazar, parkir, ongkir 4 keadaan, dan sapaan.
4. **Logika uang sebagai fungsi murni** dengan unit test: diskon, ongkir, status bayar, sapaan, stok.
5. Layar Beranda yang berfungsi + navigasi + layar pengganti yang **jujur** (tidak ada tombol palsu).

## 2. Keputusan teknis

| # | Keputusan | Alasan |
| --- | --- | --- |
| P2-D01 | **Tanpa router**; navigasi memakai state di `App.tsx` | 17 layar, satu perangkat; router menambah kompleksitas tanpa manfaat. Boleh diganti bila riwayat browser dibutuhkan |
| P2-D02 | `idb` (pembungkus IndexedDB kecil, ±1,2 kB gzip) | API promise yang aman; tanpa ini kode IndexedDB menjadi berlapis callback |
| P2-D03 | Uang: **semua fungsi murni** di `src/lib/`, tanpa IndexedDB/DOM | Bisa diuji tanpa browser; CLAUDE/CONTEXT mensyaratkan fungsi murni perhitungan |
| P2-D04 | **Parsing uang menolak pecahan** (tidak dibulatkan diam-diam) | "Jangan diam-diam mengubah nilai" — pesan jelas lebih baik daripada angka salah |
| P2-D05 | Ongkir `belum_ditentukan` disimpan sebagai `nominal: null`, **bukan 0** | Menjaga perbedaan "belum tahu" vs "gratis" sampai ke DB dan resi |
| P2-D06 | Stok bazar **dihitung** dari `bazar_items` (dibawa−terjual−ditarik) | Tidak ada angka stok bazar yang diketik langsung |
| P2-D07 | Panel peringatan penyimpanan **hanya muncul bila browser tidak menjamin** | Tidak menakut-nakuti bila tidak perlu |
| P2-D08 | Service worker **hanya di build produksi** | Saat `npm run dev`, SW menyajikan berkas lama dan merusak HMR |
| P2-D09 | Layar belum selesai menampilkan **fase kapan datangnya** | Tidak ada tombol/UX palsu; pengguna tidak mengira aplikasi rusak |
| P2-D10 | `ongkirMode` & `ongkirNominal` disimpan **eksplisit** di transaksi & parkir | Riwayat tetap akurat walau aturan ongkir berubah nanti |
